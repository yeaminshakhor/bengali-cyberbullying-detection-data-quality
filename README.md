# Bengali Cyberbullying Detection: A Data-Quality Case Study

This repository documents a Bengali/Banglish cyberbullying detection pipeline,
built originally on keyword-bootstrapped training data, and a subsequent audit
that found — and fixed — a serious generalization failure caused by that
bootstrapping process.

**The headline finding:** a classifier trained only on keyword-derived/synthetic
data scores **30.9% accuracy on real Facebook comments — worse than a naive
majority-class baseline (79.5%)**. Combining the same curated data with a small
amount of real, organically-sourced, independently-labeled text fixes this
(RandomForest: 85.2%, BanglaBERT: 86.1%), with no statistically significant
difference between the two final models (McNemar's test, p = 0.47).

If you're reusing a keyword-bootstrapped or self-labeled dataset for abusive
language detection in any low-resource language, the methodology section below
is probably the most useful part of this repo for you.

## Why this repo exists

The original goal was a straightforward Bengali cyberbullying classifier:
a keyword list, a manually-reviewed dataset built around it, and a RandomForest
model. Early results looked excellent — 98%+ accuracy across every model
tried. An audit of the underlying data found that:

1. Every "bullying" label in the dataset was generated by *running the keyword
   detector itself* over scraped text — the labels were never independent of
   the thing being evaluated (circular / self-referential labeling).
2. The "Normal" class was 92% exact duplicates of ~200 templated phrases.
3. A large portion of what looked like thousands of distinct examples were
   the same finite bank of template sentences, copied across files with
   different cosmetic ID numbers disguising the duplication.

Once a genuinely independent, real-world organic dataset was obtained and used
for evaluation, accuracy collapsed to below a trivial baseline — proving the
original numbers measured keyword-matching ability, not cyberbullying
detection.

## Methodology (short version)

1. **Data audit** — merged and deduplicated ~30 source files; found and
   recovered 768 rows with a label-corruption bug; identified the
   self-labeling circularity and the template-duplication problem.
2. **Canonical training set** — 4,713 cleaned, deduplicated, conflict-resolved
   examples from the keyword-assisted pipeline (`canonical_training_dataset_v2.csv`).
3. **Independent organic test set** — 5,860 real, expert-labeled Facebook
   comments from a public Kaggle dataset (Neutral / Political / troll /
   sexual / Threat categories, mapped to binary bullying/not-bullying),
   confirmed to have zero text overlap with the synthetic training data
   (`kaggle_organic_eval_set.csv`, with a fixed 1,172-row holdout split used
   for every reported comparison: `organic_holdout_test_set.csv`).
4. **Three-way RandomForest comparison**, 5-fold cross-validated:
   - **A: synthetic-only** → 31.8% ± 0.5% accuracy on organic test data
   - **B: organic-only** → 84.1% ± 0.9%
   - **C: combined** → 84.0% ± 0.5%
   McNemar's test: A vs. B and A vs. C are both significant (p < 0.0001);
   B vs. C is not (p = 0.617) — organic data is what fixes generalization;
   the added synthetic data does not provably help further at this sample size.
5. **BanglaBERT fine-tune (Model D)**, same combined training data, evaluated
   on the identical fixed holdout: **86.1% accuracy, macro-F1 0.793**, vs.
   RandomForest-C's 85.2% / 0.761. McNemar's test between C and D: **not
   significant (p = 0.47)** — BanglaBERT's real advantage is in macro-F1 (better
   balance on the harder Normal class: recall 0.70 vs. 0.57), not raw accuracy.
6. **Error analysis** — false positives cluster on long, calm comments about
   politics/religion (the model conflates charged topic vocabulary with
   actual hostility); false negatives cluster on very short single-word
   slurs (too little character-level signal for the char-n-gram features).

## Reproducing the results

```bash
pip install pandas scikit-learn joblib statsmodels

# Retrain RandomForest (Models A/B/C) with 5-fold CV + significance testing
python scripts/train_randomforest_abc.py

# Fine-tune BanglaBERT (Model D) — requires a GPU; Colab free tier is sufficient
python scripts/finetune_banglabert_CORRECTED.py

# Compare any two prediction files with a paired McNemar's test
python scripts/run_mcnemar.py
```

All reported numbers use the fixed `organic_holdout_test_set.csv` split
(random_state=42) so results are directly comparable across models and runs.

## Key limitations (see `docs/data_quality_action_plan.md` for full detail)

- Some training-set labels were LLM-assisted rather than purely human-annotated;
  this is disclosed rather than presented as manual annotation, and should be
  verified/corrected before being cited as ground truth in a publication.
- The organic test set is Facebook-only, from a specific time period and
  category scheme (Political/troll/sexual/Threat/Neutral); generalization to
  other platforms or newer slang is untested.
- The Normal class in the organic test set is smaller (n=240) than the
  Bullying class (n=932), which limits the precision of per-class estimates
  for that category specifically.
